{% comment %} Barra de filtros (docs/09 "filter-bar", docs/12, docs/19). Parâmetros: chips (listing.Chip), options (listing.FilterOptions), selected (listing.selected), filters (listing.ListingFilters), region_id (região trocada pelo HTMX); count_oob: a contagem fica fora da região (id="listing-count") e é atualizada junto; na busca: query (termo, vai como campo oculto) e clear_url (limpa sem perder o termo). Sem JavaScript: formulário GET na própria página e chips como links. Com HTMX: mudar um campo (ou remover um chip) busca a mesma URL, troca só a região da lista e põe a URL no histórico (hx-push-url), então voltar no navegador desfaz o filtro. Os campos têm id para o HTMX devolver o foco ao mesmo campo depois da troca. Comportamentos em app.js. {% endcomment %}
